Unit 1 Key Formulas & Definitions Summary

D'Alembert's Ratio Test
$\lim_{n\to\infty} \frac{u_n}{u_{n+1}} = l$. Converges if $l > 1$, diverges if $l < 1$, fails if $l = 1$.
Raabe's Test (Fallback)
$\lim_{n\to\infty} n\left(\frac{u_n}{u_{n+1}} - 1\right) = l$. Converges if $l > 1$, diverges if $l < 1$.
p-Series Test
$\sum_{n=1}^\infty \frac{1}{n^p}$ converges if $p > 1$ and diverges if $p \le 1$.
Leibnitz Alternating Series Test
$\sum (-1)^{n-1}u_n$ converges if (i) $u_{n+1} \le u_n$ and (ii) $\lim_{n\to\infty} u_n = 0$.
Cauchy's Integral Test
$\sum u_n$ and $\int_1^\infty f(x)\,dx$ behave identically if $f(x)$ is positive, continuous & decreasing.
Taylor / Maclaurin Expansion
$f(x) = f(0) + x f'(0) + \frac{x^2}{2!} f''(0) + \frac{x^3}{3!} f'''(0) + \cdots$
