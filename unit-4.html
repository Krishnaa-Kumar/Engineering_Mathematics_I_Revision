Multivariable Calculus (Partial Differentiation)

1. Homogeneous Functions & Euler’s Theorem (1st Order)

A function $f(x,y)$ is homogeneous of degree $n$ if $f(tx, ty) = t^n f(x,y)$. Euler’s Theorem simplifies first-order partial derivatives.

  • Statement: If $u = f(x,y)$ is homogeneous of degree $n$, then $x\frac{\partial u}{\partial x} + y\frac{\partial u}{\partial y} = n u$.
  • Three Variables: $x\frac{\partial u}{\partial x} + y\frac{\partial u}{\partial y} + z\frac{\partial u}{\partial z} = n u$.
Key Formula / Derivation Condition 
x * (du/dx) + y * (du/dy) = n * u
Three variables: x * u_x + y * u_y + z * u_z = n * u

2. Euler’s 2nd-Order Theorem & Both Key Deductions

A mandatory 10-mark theorem in Section C of the IKG-PTU examination.

  • Theorem Statement: If $u$ is homogeneous of degree $n$, then $x^2 \frac{\partial^2 u}{\partial x^2} + 2xy \frac{\partial^2 u}{\partial x\partial y} + y^2 \frac{\partial^2 u}{\partial y^2} = n(n-1)u$.
  • Deduction 1 ($f(u) = \phi(x,y)$ homogeneous of degree $n$): $x\frac{\partial u}{\partial x} + y\frac{\partial u}{\partial y} = n\frac{f(u)}{f'(u)} = F(u)$.
  • Deduction 2: $x^2 \frac{\partial^2 u}{\partial x^2} + 2xy \frac{\partial^2 u}{\partial x\partial y} + y^2 \frac{\partial^2 u}{\partial y^2} = F(u)[F'(u) - 1]$.
Key Formula / Derivation Condition 
x^2 * u_xx + 2xy * u_xy + y^2 * u_yy = n(n-1) * u
Deduction 1: x*u_x + y*u_y = n * [f(u)/f'(u)] = F(u)
Deduction 2: x^2*u_xx + 2xy*u_xy + y^2*u_yy = F(u) * [F'(u) - 1]

3. Maxima & Minima for Functions of Two Variables

Testing extremum points for $z = f(x,y)$ using second-order partial derivative discriminant.

  • Step 1: Find stationary points by solving simultaneously: $p = \frac{\partial f}{\partial x} = 0$ and $q = \frac{\partial f}{\partial y} = 0$.
  • Step 2: Compute $r = \frac{\partial^2 f}{\partial x^2}$, $s = \frac{\partial^2 f}{\partial x\partial y}$, $t = \frac{\partial^2 f}{\partial y^2}$.
  • Local Minimum: If $rt - s^2 > 0$ and $r > 0$.
  • Local Maximum: If $rt - s^2 > 0$ and $r < 0$.
  • Saddle Point (No Extremum): If $rt - s^2 < 0$.
  • Inconclusive Test: If $rt - s^2 = 0$ (further investigation required).
Key Formula / Derivation Condition 
Stationary Points: f_x = 0 and f_y = 0
Discriminant Delta = rt - s^2, where r = f_xx, s = f_xy, t = f_yy
- If Delta > 0 and r > 0 => Local Minimum
- If Delta > 0 and r < 0 => Local Maximum
- If Delta < 0          => Saddle Point (No Extremum)
- If Delta = 0          => Inconclusive

4. Chain Rule & Total Differential

Computing derivatives when variables depend on intermediate or single independent variables.

  • Total Differential: $du = \frac{\partial u}{\partial x}dx + \frac{\partial u}{\partial y}dy + \frac{\partial u}{\partial z}dz$.
  • Chain Rule (Composite): If $u = f(x,y)$ and $x = \phi(t), y = \psi(t)$, then $\frac{du}{dt} = \frac{\partial u}{\partial x}\frac{dx}{dt} + \frac{\partial u}{\partial y}\frac{dy}{dt}$.
Key Formula / Derivation Condition 
du = (du/dx)*dx + (du/dy)*dy
du/dt = (du/dx)*(dx/dt) + (du/dy)*(dy/dt)

2 & 5 Marks Exam Question 1

U4-Q1: Basic Definitions & Maxima/Minima Working Conditions
Verified Model Solution & Derivation:
Problem Statement: Define Partial Derivative, Homogeneous Function, Chain Rule, Composite Function, Total Derivative, and state the conditions for Maxima & Minima of $f(x, y)$.
PTU Evaluator Tip: Writing the 4-point $rt - s^2$ working rule cleanly at the top of any 10-mark Maxima/Minima question guarantees 3 marks before you even touch the numbers.
1. Definitions (Partial Derivative, Homogeneous, Composite, Total Derivative)
• Partial Derivative: $f_x = \lim_{h\to 0} \frac{f(x+h, y) - f(x, y)}{h}$ (treating $y$ as constant).
• Homogeneous Function: $f(x,y)$ has degree $n$ if $f(tx, ty) = t^n f(x,y)$.
• Composite Function & Chain Rule: If $z = f(x,y)$ where $x = \phi(u,v), y = \psi(u,v)$, then $\frac{\partial z}{\partial u} = \frac{\partial z}{\partial x}\frac{\partial x}{\partial u} + \frac{\partial z}{\partial y}\frac{\partial y}{\partial u}$.
• Total Derivative: If $x = x(t), y = y(t)$, then $\frac{dz}{dt} = \frac{\partial z}{\partial x}\frac{dx}{dt} + \frac{\partial z}{\partial y}\frac{dy}{dt}$.
2. Necessary & Sufficient Conditions for Maxima/Minima of f(x, y)
1. Find stationary points where $p = f_x = 0$ and $q = f_y = 0$.
2. Compute $r = f_{xx}, \; s = f_{xy}, \; t = f_{yy}$ at $(a, b)$.
• Maximum: $rt - s^2 > 0$ and $r < 0$.
• Minimum: $rt - s^2 > 0$ and $r > 0$.
• Saddle Point: $rt - s^2 < 0$. (If $rt - s^2 = 0$, case is doubtful).
5 Marks Each Exam Question 2

U4-Q2: All 6 Chain Rule & Euler 1st-Order Problems
Verified Model Solution & Derivation:
Problem Statement: Solve all 6 problems:
(I) Find $\frac{dz}{dt}$ for $z = xy^2 + x^2y$, $x = at^2$, $y = 2at$ (and $y = -2at$);
(II) Find $z_x, z_y$ for $\log z = \log(u^2+v)$, $u = e^{x^2+y^2}$, $v = x^2+y$;
(III) Find $w_r, w_s$ for $w = x^2+y^2$, $x = r-s$, $y = r+s$;
(IV) Prove $x u_x + y u_y + z u_z = 0$ for $u = f(x/y, y/z, z/x)$;
(V) Prove $x z_x + y z_y = \sin 2z$ for $z = \tan^{-1}\left(\frac{x^3+y^3}{x-y}\right)$;
(VI) Prove $(u_x+u_y+u_z)^2 = \frac{9}{(x+y+z)^2}$ for $u = \log(x^3+y^3+z^3-3xyz)$.
PTU Evaluator Tip: For (V), apply Euler's theorem to $f = \tan z$ (degree $3-1=2$) instead of differentiating $\tan^{-1}$ directly. For (VI), factor the denominator using $(x+y+z)(x^2+y^2+z^2-xy-yz-zx)$.
(I) Total Derivative dz/dt for z = xy² + x²y
$$\frac{dz}{dt} = (y^2 + 2xy)\frac{dx}{dt} + (2xy + x^2)\frac{dy}{dt}$$
• For $x = at^2, y = 2at$: $= (4a^2t^2 + 4a^2t^3)(2at) + (4a^2t^3 + a^2t^4)(2a) = \mathbf{16a^3t^3 + 10a^3t^4}$.
• For $x = at^2, y = -2at$: $= (4a^2t^2 - 4a^2t^3)(2at) + (-4a^2t^3 + a^2t^4)(-2a) = \mathbf{16a^3t^3 - 10a^3t^4}$.
(II) Chain Rule for log z = log(u² + v) and (III) w = x² + y²
• (II) $z = u^2 + v \implies z_x = 2u\cdot u_x + v_x = \mathbf{4xe^{2(x^2+y^2)} + 2x}$;   $z_y = \mathbf{4ye^{2(x^2+y^2)} + 1}$.
• (III) $w_r = 2x(1) + 2y(1) = 2(r-s+r+s) = \mathbf{4r}$;   $w_s = 2x(-1) + 2y(1) = \mathbf{4s}$.
(IV) u = f(x/y, y/z, z/x) and (V) z = tan⁻¹((x³ + y³)/(x - y))
• (IV) Let $p=x/y, q=y/z, r=z/x$. Computing $x u_x + y u_y + z u_z$ gives $\left(\frac{x}{y}f_p - \frac{z}{x}f_r\right) + \left(-\frac{x}{y}f_p + \frac{y}{z}f_q\right) + \left(-\frac{y}{z}f_q + \frac{z}{x}f_r\right) = \mathbf{0}$.
• (V) $f = \tan z = \frac{x^3+y^3}{x-y}$ has degree $n=2 \implies x\sec^2 z\,z_x + y\sec^2 z\,z_y = 2\tan z \implies x z_x + y z_y = \mathbf{\sin 2z}$.
(VI) u = log(x³ + y³ + z³ - 3xyz)
$$u_x + u_y + u_z = \frac{3(x^2+y^2+z^2-xy-yz-zx)}{(x+y+z)(x^2+y^2+z^2-xy-yz-zx)} = \frac{3}{x+y+z} \implies (u_x+u_y+u_z)^2 = \mathbf{\frac{9}{(x+y+z)^2}}$$
10 Marks Exam Question 3

U4-Q3: Euler's 2nd-Order Theorem Proof & Both Deductions
Verified Model Solution & Derivation:
Problem Statement: Prove Euler's 2nd-Order Theorem $x^2 z_{xx} + 2xy z_{xy} + y^2 z_{yy} = n(n-1)z$, and deduce:
(1) $x^2 u_{xx} + 2xy u_{xy} + y^2 u_{yy} = -\frac{\sin u \cos 2u}{4\cos^3 u}$ for $u = \sin^{-1}\left(\frac{x+y}{\sqrt{x}+\sqrt{y}}\right)$;
(2) $x^2 u_{xx} + 2xy u_{xy} + y^2 u_{yy} = -\sin 2u \sin^2 u$ for $u = \tan^{-1}\left(\frac{y^2}{x}\right)$.
PTU Evaluator Tip: Memorize the master corollary: if $F(u)$ is homogeneous of degree $n$, then $x u_x + y u_y = n\frac{F(u)}{F'(u)} = \phi(u)$ and $x^2 u_{xx} + 2xy u_{xy} + y^2 u_{yy} = \phi(u)[\phi'(u) - 1]$.
Step 1: Proof of Euler's 2nd-Order Theorem
Start with $x z_x + y z_y = nz$. Differentiate w.r.t. $x$ and $y$:
$$x z_{xx} + y z_{xy} = (n-1)z_x \quad (1), \qquad x z_{xy} + y z_{yy} = (n-1)z_y \quad (2)$$
Multiply (1) by $x$, (2) by $y$, and add: $x^2 z_{xx} + 2xy z_{xy} + y^2 z_{yy} = (n-1)(x z_x + y z_y) = \mathbf{n(n-1)z}$.
Step 2: Deduction 1 — u = sin⁻¹((x + y) / (√x + √y))
$z = \sin u = \frac{x+y}{\sqrt{x}+\sqrt{y}}$ has degree $n = 1 - \frac{1}{2} = \frac{1}{2}$.
$$\phi(u) = \frac{1}{2}\frac{\sin u}{\cos u} = \frac{1}{2}\tan u \implies \phi(u)[\phi'(u)-1] = \frac{1}{2}\tan u\left(\frac{1}{2}\sec^2 u - 1\right) = \mathbf{-\frac{\sin u \cos 2u}{4\cos^3 u}}$$
Step 3: Deduction 2 — u = tan⁻¹(y² / x)
$z = \tan u = \frac{y^2}{x}$ has degree $n = 2 - 1 = 1$.
$$\phi(u) = 1 \cdot \frac{\tan u}{\sec^2 u} = \sin u\cos u = \frac{1}{2}\sin 2u$$
$$x^2 u_{xx} + 2xy u_{xy} + y^2 u_{yy} = \frac{1}{2}\sin 2u (\cos 2u - 1) = \frac{1}{2}\sin 2u (-2\sin^2 u) = \mathbf{-\sin 2u \sin^2 u}$$
10 Marks Each Exam Question 4

U4-Q4: All 4 Maxima & Minima Problems (Algebraic & Word Problems)
Verified Model Solution & Derivation:
Problem Statement: Solve all 4 Maxima/Minima problems:
(I) $f(x,y) = x^4 + y^4 - 2x^2 + 4xy - 2y^2$;
(II) $f(x,y) = x^3 + y^3 - 63(x+y) + 12xy$;
(III) Sum of 3 positive numbers is constant ($x+y+z=c$), prove product $xyz$ is max when $x=y=z$;
(IV) Open-top rectangular box of volume $32\text{ m}^3$, find dimensions for least material.
PTU Evaluator Tip: In (I) and (II), subtract or add $f_x = 0$ and $f_y = 0$ to factor $(x-y)$ or $(x+y)$ immediately. In (IV), 'open at the top' means Surface Area $S = xy + 2yz + 2zx$ (only one base!).
(I) f(x, y) = x⁴ + y⁴ - 2x² + 4xy - 2y²
$f_x = 4x^3 - 4x + 4y = 0$ and $f_y = 4y^3 + 4x - 4y = 0$. Adding gives $x^3 + y^3 = 0 \implies y = -x$.
Points: $(0,0)$ [Saddle], $(\sqrt{2}, -\sqrt{2})$ and $(-\sqrt{2}, \sqrt{2})$ where $r = 20 > 0, rt-s^2 = 384 > 0 \implies$ Minima = -8.
(II) f(x, y) = x³ + y³ - 63(x + y) + 12xy
$x^2 + 4y - 21 = 0$ and $y^2 + 4x - 21 = 0$. Subtracting gives $(x-y)(x+y-4)=0$.
• At $(-7,-7)$: $r = -42 < 0, rt-s^2 > 0 \implies$ Maximum = 784.
• At $(3,3)$: $r = 18 > 0, rt-s^2 > 0 \implies$ Minimum = -216. (Points $(5,-1), (-1,5)$ are saddles).
(III) Maximum Product P = xyz Given x + y + z = c
$P = xy(c - x - y) \implies P_x = y(c - 2x - y) = 0, \; P_y = x(c - x - 2y) = 0 \implies x = y = z = \frac{c}{3}$.
At $(\frac{c}{3}, \frac{c}{3})$: $r = -\frac{2c}{3} < 0, \; rt-s^2 = \frac{c^2}{3} > 0 \implies$ Maximum when x = y = z.
(IV) Open-Top Rectangular Box (Volume = 32 m³)
$z = \frac{32}{xy} \implies S = xy + \frac{64}{x} + \frac{64}{y}$. Setting $S_x = 0, S_y = 0 \implies x^2 y = 64, x y^2 = 64 \implies x = y = 4, z = 2$.
At $(4,4)$: $r = 2 > 0, rt-s^2 = 3 > 0 \implies$ Dimensions: 4 m × 4 m × 2 m.
5 & 10 Marks Exam Question 5

U4-Q5, Q6, Q7: All 3 Partial Differential Equation Identities
Verified Model Solution & Derivation:
Problem Statement: Solve:
Q5: Find $n$ if $\theta = t^n e^{-r^2/(4t)}$ satisfies $\frac{1}{r^2}\frac{\partial}{\partial r}\left(r^2\frac{\partial\theta}{\partial r}\right) = \frac{\partial\theta}{\partial t}$;
Q6: If $r^2 = x^2+y^2+z^2$, prove $\nabla^2(r^m) = m(m+1)r^{m-2}$;
Q7: If $u = \sin^{-1}\left(\frac{x^2+y^2}{x+y}\right)$, prove $x u_x + y u_y = \tan u$ and $x^2 u_{xx} + 2xy u_{xy} + y^2 u_{yy} = \tan^3 u$.
PTU Evaluator Tip: In Q6, always differentiate $r$ implicitly via $r^2 = x^2 + y^2 + z^2 \implies \frac{\partial r}{\partial x} = \frac{x}{r}$ rather than expanding square roots.
Q5: Heat Equation Similarity Solution θ = tⁿ e^(-r² / 4t)
$$\frac{1}{r^2}\frac{\partial}{\partial r}\left(r^2\frac{\partial\theta}{\partial r}\right) = \left(-\frac{3}{2}t^{n-1} + \frac{r^2}{4}t^{n-2}\right)e^{-r^2/(4t)}, \quad \frac{\partial\theta}{\partial t} = \left(n t^{n-1} + \frac{r^2}{4}t^{n-2}\right)e^{-r^2/(4t)}$$
Equating coefficients of $t^{n-1}$ gives $n = \mathbf{-\frac{3}{2}}$.
Q6: 3D Laplacian of r^m where r² = x² + y² + z²
$\frac{\partial(r^m)}{\partial x} = m r^{m-2} x \implies \frac{\partial^2(r^m)}{\partial x^2} = m r^{m-2} + m(m-2)r^{m-4}x^2$.
Summing over $x, y, z$: $\nabla^2(r^m) = 3m r^{m-2} + m(m-2)r^{m-4}(x^2+y^2+z^2) = \mathbf{m(m+1)r^{m-2}}$.
Q7: u = sin⁻¹((x² + y²) / (x + y))
$z = \sin u$ has degree $n = 2 - 1 = 1 \implies x u_x + y u_y = \frac{\sin u}{\cos u} = \mathbf{\tan u}$.
2nd order: $\phi(u)[\phi'(u)-1] = \tan u(\sec^2 u - 1) = \mathbf{\tan^3 u}$.
