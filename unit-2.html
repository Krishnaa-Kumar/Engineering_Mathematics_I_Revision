Applications of Definite Integrals

Arc length of plane curves (rectification), surface areas and volumes of revolution for Cartesian, parametric, and polar curves (Cycloids, Ellipses, Cardioids, Circles).

1. Length of Plane Curves (Arc Length Formulas)

Arc length $s$ measures the distance along a curved line between two points.

  • Cartesian Form: $s = \int_a^b \sqrt{1 + \left(\frac{dy}{dx}\right)^2}\,dx$ or $s = \int_c^d \sqrt{1 + \left(\frac{dx}{dy}\right)^2}\,dy$.
  • Parametric Form: $s = \int_{t_1}^{t_2} \sqrt{\left(\frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2}\,dt$.
  • Polar Form: $s = \int_{\theta_1}^{\theta_2} \sqrt{r^2 + \left(\frac{dr}{d\theta}\right)^2}\,d\theta$.
Key Formula / Derivation Condition 
Cartesian:  ds = sqrt(1 + (dy/dx)^2) dx
Parametric: ds = sqrt((dx/dt)^2 + (dy/dt)^2) dt
Polar:      ds = sqrt(r^2 + (dr/dtheta)^2) dtheta

2. Surface Area of Solids of Revolution

When a plane curve is revolved $360^\circ$ around an axis of symmetry, the area of the generated curved surface is computed via differential element $dS = 2\pi y\,ds$.

  • About x-axis (Cartesian): $S = 2\pi \int_a^b y \sqrt{1 + (y')^2}\,dx$.
  • About x-axis (Parametric): $S = 2\pi \int_{t_1}^{t_2} y(t) \sqrt{(x')^2 + (y')^2}\,dt$.
  • About Initial Line (Polar): $S = 2\pi \int_{\theta_1}^{\theta_2} r\sin\theta \sqrt{r^2 + (r')^2}\,d\theta$.
Key Formula / Derivation Condition 
S_x = 2 * pi * int y * sqrt(1 + (dy/dx)^2) dx
S_polar = 2 * pi * int r * sin(theta) * sqrt(r^2 + (dr/dtheta)^2) dtheta
Cycloid Surface about x-axis: S = 64/3 * pi * a^2

3. Volume of Solids of Revolution

The volume of a solid generated by rotating a bounded region around an axis.

  • About x-axis: $V = \pi \int_a^b y^2\,dx$.
  • About y-axis: $V = \pi \int_c^d x^2\,dy$.
  • Polar Form (About initial line $\theta=0$): $V = \frac{2}{3}\pi \int_{\theta_1}^{\theta_2} r^3 \sin\theta\,d\theta$.
Key Formula / Derivation Condition 
V_x = pi * int_a^b y^2 dx
V_polar = (2/3) * pi * int r^3 * sin(theta) dtheta
Cardioid r = a(1+cos theta) Volume about initial line: V = (8/3) * pi * a^3

4. Standard High-Yield Exam Curves

Frequently asked curves in IKG-PTU university examinations with standard geometric invariants.

  • Cardioid $r = a(1+\cos\theta)$: Total Perimeter = $8a$, Volume about initial line = $\frac{8}{3}\pi a^3$, Surface Area = $\frac{32}{5}\pi a^2$.
  • Cycloid $x = a(\theta - \sin\theta), y = a(1 - \cos\theta)$: One arch length = $8a$ ($\theta \in [0, 2\pi]$), Surface area about base = $\frac{64}{3}\pi a^2$.
  • Astroid $x^{2/3} + y^{2/3} = a^{2/3}$: Parametric $x = a\cos^3 t, y = a\sin^3 t$, Total Perimeter = $6a$.
Key Formula / Derivation Condition 
Cardioid: r = a(1 + cos theta) => Perimeter = 8a, Surface = (32/5)*pi*a^2
Cycloid:  x = a(t - sin t), y = a(1 - cos t) => Arch Length = 8a
Astroid:  x^(2/3) + y^(2/3) = a^(2/3) => Total Perimeter = 6a

2 Marks Each Exam Question 1

U2-Q1 & Q2: All Formulas of Arc Length, Volume & Surface Area
Verified Model Solution & Derivation:
Problem Statement: Write all formulas for Length of Curve (Cartesian, Parametric, Polar), Volume of Solid of Revolution, and Surface Area of Solid of Revolution.
PTU Evaluator Tip: Notice the pattern: $ds$ stays identical in both Arc Length ($\int ds$) and Surface Area ($\int 2\pi y\,ds$), whereas Volume uses $\pi y^2\,dx$ without a square root.
1. Length of Curve Formulas (s)
• Cartesian: $s = \int_{a}^{b} \sqrt{1 + \left(\frac{dy}{dx}\right)^2}\,dx$  or  $s = \int_{c}^{d} \sqrt{1 + \left(\frac{dx}{dy}\right)^2}\,dy$
• Parametric: $s = \int_{t_1}^{t_2} \sqrt{\left(\frac{dx}{dt}\right)^2 + \left(\frac{dy}{dt}\right)^2}\,dt$
• Polar: $s = \int_{\theta_1}^{\theta_2} \sqrt{r^2 + \left(\frac{dr}{d\theta}\right)^2}\,d\theta$
2. Volume of Solid of Revolution (V)
• About x-axis: $V = \int_{a}^{b} \pi y^2\,dx$
• About y-axis: $V = \int_{c}^{d} \pi x^2\,dy$
• Polar about initial line (θ = 0): $V = \int_{\theta_1}^{\theta_2} \frac{2}{3}\pi r^3 \sin\theta\,d\theta$
3. Surface Area of Solid of Revolution (S)
• About x-axis: $S = \int 2\pi y\,ds$
• About y-axis: $S = \int 2\pi x\,ds$
• Polar about initial line (θ = 0): $S = \int_{\theta_1}^{\theta_2} 2\pi (r\sin\theta)\sqrt{r^2 + \left(\frac{dr}{d\theta}\right)^2}\,d\theta$
5 Marks Each Exam Question 2

U2-Q3: Length of Curves — All 5 Standard Problems
Verified Model Solution & Derivation:
Problem Statement: Find arc length of:
(I) Parabola $x^2 = 4ay$ from vertex $(0,0)$ to $(2a,a)$;
(II) $y = \frac{1}{2}x^2 + 1$ from $x=0$ to $x=2$;
(III) $y^2 = 4ax$ cut off by latus rectum;
(IV) $x^2 = 16y$ cut off by latus rectum;
(V) $y^2 = 4x$ cut off by line $y = x$.
PTU Evaluator Tip: Check whether the question asks for 'vertex to ONE end of latus rectum' (single integral) or 'cut off by latus rectum' (both symmetric halves $\implies$ multiply by $2$!).
(I) Parabola x² = 4ay from vertex (0,0) to (2a, a)
$\frac{dy}{dx} = \frac{x}{2a} \implies s = \int_{0}^{2a} \sqrt{1 + \frac{x^2}{4a^2}}\,dx = \frac{1}{2a}\left[\frac{x}{2}\sqrt{4a^2+x^2} + 2a^2\log(x+\sqrt{4a^2+x^2})\right]_{0}^{2a}$
$$s = \mathbf{a\left[\sqrt{2} + \log(\sqrt{2} + 1)\right]}$$
(II) Curve y = (1/2)x² + 1 from x = 0 to x = 2
$\frac{dy}{dx} = x \implies s = \int_{0}^{2} \sqrt{1+x^2}\,dx = \left[\frac{x}{2}\sqrt{1+x^2} + \frac{1}{2}\log(x+\sqrt{1+x^2})\right]_{0}^{2} = \mathbf{\sqrt{5} + \frac{1}{2}\log(2 + \sqrt{5})}$
(III) Parabola y² = 4ax cut off by latus rectum (x = 0 to a, both halves)
$\frac{dy}{dx} = \sqrt{\frac{a}{x}} \implies s = 2\int_{0}^{a} \sqrt{1 + \frac{a}{x}}\,dx$. Put $x = a\tan^2\theta$:
$$s = 4a\int_{0}^{\pi/4} \sec^3\theta\,d\theta = \mathbf{2a\left[\sqrt{2} + \log(\sqrt{2} + 1)\right]}$$
(IV) Parabola x² = 16y cut off by latus rectum
Comparing with $x^2 = 4ay \implies 4a = 16 \implies a = 4$.
For both symmetric halves from $(-8, 4)$ to $(8, 4)$: $s = 2 \times 4[\sqrt{2} + \log(\sqrt{2}+1)] = \mathbf{8\left[\sqrt{2} + \log(\sqrt{2} + 1)\right]}$.
(V) Parabola y² = 4x cut off by line y = x
Intersection: $x^2 = 4x \implies x = 0, 4$. Here $\frac{dy}{dx} = \frac{1}{\sqrt{x}}$.
$$s = \int_{0}^{4} \sqrt{1 + \frac{1}{x}}\,dx = \left[\sqrt{x(x+1)} + \log(\sqrt{x} + \sqrt{x+1})\right]_{0}^{4} = \mathbf{2\sqrt{5} + \log(2 + \sqrt{5})}$$
5 Marks Exam Question 3

U2-Q4: Perimeter (Length) of Circle & Ellipse
Verified Model Solution & Derivation:
Problem Statement: Find the total perimeter of (i) Circle $x^2 + y^2 = a^2$ and (ii) Ellipse $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$.
PTU Evaluator Tip: Use parametric form $x = a\cos\theta, y = b\sin\theta$ with limits $\theta \in [0, \pi/2]$ and multiply by $4$ for all four quadrants.
(i) Perimeter of Circle x² + y² = a²
Put $x = a\cos\theta, \; y = a\sin\theta$. By symmetry across 4 quadrants:
$$s = 4\int_{0}^{\pi/2} \sqrt{(-a\sin\theta)^2 + (a\cos\theta)^2}\,d\theta = 4\int_{0}^{\pi/2} a\,d\theta = 4a\left(\frac{\pi}{2}\right) = \mathbf{2\pi a}$$
(ii) Perimeter of Ellipse x²/a² + y²/b² = 1 (a > b)
Put $x = a\cos\theta, \; y = b\sin\theta$. Using $b^2 = a^2(1 - e^2)$:
$$s = 4\int_{0}^{\pi/2} \sqrt{a^2\sin^2\theta + b^2\cos^2\theta}\,d\theta = 4a\int_{0}^{\pi/2} \sqrt{1 - e^2\cos^2\theta}\,d\theta$$
Expand Binomially & Integrate Using Wallis' Formula
$$s = 4a\int_{0}^{\pi/2} \left(1 - \frac{1}{2}e^2\cos^2\theta - \frac{1}{8}e^4\cos^4\theta - \cdots\right)d\theta = \mathbf{2\pi a\left[1 - \left(\frac{1}{2}\right)^2 e^2 - \left(\frac{1\cdot 3}{2\cdot 4}\right)^2 \frac{e^4}{3} - \cdots\right]}$$
10 Marks Exam Question 4

U2-Q5: Surface Area of All Cycloid Variants About x-axis
Verified Model Solution & Derivation:
Problem Statement: Find the surface area generated by revolving one arch about the $x$-axis for:
(I) $x = a(\theta - \sin\theta), \; y = a(1 - \cos\theta)$;
(II) $x = a(\theta + \sin\theta), \; y = a(1 + \cos\theta)$;
(III) $x = a(\theta + \sin\theta), \; y = a(1 - \cos\theta)$ (from handwritten notes).
PTU Evaluator Tip: Watch the signs carefully! When the signs inside $x$ and $y$ match ($-$ and $-$, or $+$ and $+$), $S = \frac{64}{3}\pi a^2$. When the signs are opposite ($+$ and $-$), $S = \frac{32}{3}\pi a^2$.
(I) Standard Cycloid x = a(θ - sin θ), y = a(1 - cos θ) [θ: 0 to 2π]
$$\frac{ds}{d\theta} = \sqrt{a^2(1-\cos\theta)^2 + a^2\sin^2\theta} = 2a\sin\left(\frac{\theta}{2}\right)$$
$$S = \int_{0}^{2\pi} 2\pi a(1-\cos\theta)\cdot 2a\sin\left(\frac{\theta}{2}\right)d\theta = 8\pi a^2 \int_{0}^{2\pi} \sin^3\left(\frac{\theta}{2}\right)d\theta$$
Put $\frac{\theta}{2} = t$: $S = 16\pi a^2 \cdot 2\int_{0}^{\pi/2} \sin^3 t\,dt = 32\pi a^2\left(\frac{2}{3}\right) = \mathbf{\frac{64}{3}\pi a^2}$.
(II) Cycloid x = a(θ + sin θ), y = a(1 + cos θ) [θ: -π to π]
$$\frac{ds}{d\theta} = \sqrt{a^2(1+\cos\theta)^2 + a^2\sin^2\theta} = 2a\cos\left(\frac{\theta}{2}\right)$$
$$S = 2\int_{0}^{\pi} 2\pi a(1+\cos\theta)\cdot 2a\cos\left(\frac{\theta}{2}\right)d\theta = 16\pi a^2 \int_{0}^{\pi} \cos^3\left(\frac{\theta}{2}\right)d\theta = \mathbf{\frac{64}{3}\pi a^2}$$
(III) Handwritten Notes Variant: x = a(θ + sin θ), y = a(1 - cos θ) [θ: 0 to 2π]
Here $\frac{ds}{d\theta} = 2a\cos(\theta/2)$ and $y = 2a\sin^2(\theta/2)$:
$$S = 2\int_{0}^{\pi} 2\pi \cdot 2a\sin^2\left(\frac{\theta}{2}\right) \cdot 2a\cos\left(\frac{\theta}{2}\right)d\theta = 16\pi a^2 \left[2\cdot\frac{\sin^3(\theta/2)}{3}\right]_{0}^{\pi} = \mathbf{\frac{32}{3}\pi a^2}$$
10 Marks Exam Question 5

U2-Q6: Surface Area of Ellipses About x-axis (General & Specific)
Verified Model Solution & Derivation:
Problem Statement: Find the surface area of the solid generated by revolving about the $x$-axis:
(I) General ellipse $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$ ($a > b$);
(II) Specific ellipse $x^2 + 4y^2 = 16$.
PTU Evaluator Tip: Solve the general ellipse using eccentricity $e^2 = 1 - b^2/a^2$. For $x^2 + 4y^2 = 16$, divide by $16$ first to get $a = 4, b = 2$, then substitute into the general formula.
(I) General Ellipse x²/a² + y²/b² = 1: Find ds/dx
$\frac{dy}{dx} = -\frac{b^2 x}{a^2 y} \implies y\sqrt{1 + (y')^2} = \frac{b}{a^2}\sqrt{a^4 - (a^2 - b^2)x^2} = \frac{be}{a}\sqrt{\left(\frac{a}{e}\right)^2 - x^2}$.
Integrate from x = 0 to a (Multiply by 2 for symmetry)
$$S = \frac{4\pi be}{a}\int_{0}^{a} \sqrt{\frac{a^2}{e^2} - x^2}\,dx = \frac{4\pi be}{a}\left[\frac{a}{2}\cdot\frac{b}{e} + \frac{a^2}{2e^2}\sin^{-1}(e)\right] = \mathbf{2\pi b^2 + \frac{2\pi ab}{e}\sin^{-1}(e)}$$
(II) Specific Ellipse x² + 4y² = 16
Divide by $16$: $\frac{x^2}{16} + \frac{y^2}{4} = 1 \implies a = 4, \; b = 2, \; e = \sqrt{1 - \frac{4}{16}} = \frac{\sqrt{3}}{2}$.
$$S = 2\pi(2)^2 + \frac{2\pi(4)(2)}{\sqrt{3}/2}\sin^{-1}\left(\frac{\sqrt{3}}{2}\right) = 8\pi + \frac{32\pi}{\sqrt{3}}\left(\frac{\pi}{3}\right) = \mathbf{8\pi + \frac{32\pi^2}{3\sqrt{3}}}$$
10 Marks Exam Question 6

U2-Q7: Volume & Surface Area of Both Cardioids About θ = 0
Verified Model Solution & Derivation:
Problem Statement: Find the volume and surface area generated by revolving about the initial line ($\theta = 0$) for:
(I) $r = a(1 - \cos\theta)$;
(II) $r = a(1 + \cos\theta)$.
PTU Evaluator Tip: Limits of $\theta$ for cardioid revolution about $\theta = 0$ are ALWAYS $0$ to $\pi$ (upper half generates the entire 3D solid). Both cardioids yield the exact same Volume ($\frac{8}{3}\pi a^3$) and Surface Area ($\frac{32}{5}\pi a^2$).
(I) Cardioid r = a(1 - cos θ) — Volume
$$V = \int_{0}^{\pi} \frac{2}{3}\pi r^3 \sin\theta\,d\theta = \frac{2}{3}\pi a^3 \int_{0}^{\pi} (1 - \cos\theta)^3 \sin\theta\,d\theta$$
Put $1 - \cos\theta = t \implies \sin\theta\,d\theta = dt$ ($t: 0 \to 2$):
$$V = \frac{2}{3}\pi a^3 \left[\frac{t^4}{4}\right]_{0}^{2} = \mathbf{\frac{8}{3}\pi a^3}$$
(I) Cardioid r = a(1 - cos θ) — Surface Area
$\frac{ds}{d\theta} = \sqrt{r^2 + (r')^2} = 2a\sin(\theta/2)$.
$$S = \int_{0}^{\pi} 2\pi a(1-\cos\theta)\sin\theta \cdot 2a\sin\left(\frac{\theta}{2}\right)d\theta = 16\pi a^2 \int_{0}^{\pi} \sin^4\left(\frac{\theta}{2}\right)\cos\left(\frac{\theta}{2}\right)d\theta = \mathbf{\frac{32}{5}\pi a^2}$$
(II) Cardioid r = a(1 + cos θ) — Volume & Surface Area
• Volume: $V = \frac{2}{3}\pi a^3 \int_{0}^{\pi} (1 + \cos\theta)^3 \sin\theta\,d\theta = \frac{2}{3}\pi a^3 \left[-\frac{(1+\cos\theta)^4}{4}\right]_{0}^{\pi} = \mathbf{\frac{8}{3}\pi a^3}$.
• Surface Area: $\frac{ds}{d\theta} = 2a\cos(\theta/2) \implies S = 16\pi a^2 \int_{0}^{\pi} \cos^4(\theta/2)\sin(\theta/2)\,d\theta = \mathbf{\frac{32}{5}\pi a^2}$.
5 Marks Each Exam Question 7

U2-Q8: Volume & Surface Area of All 5 Circles (Cartesian & Polar)
Verified Model Solution & Derivation:
Problem Statement: Find Volume and Surface Area of revolution for:
(I) $x^2 + y^2 = a^2$ about $x$-axis;
(II) $x^2 + y^2 = 4$ about $x$-axis;
(III) $x^2 + y^2 = 9$ about $x$-axis;
(IV) $r = 2a\sin\theta$ about $\theta = \pi/2$;
(V) $r = 2a\cos\theta$ about $\theta = 0$.
PTU Evaluator Tip: Every circle revolved about a diameter generates a sphere of radius $R$ with $V = \frac{4}{3}\pi R^3$ and $S = 4\pi R^2$. In polar form, $r = 2a\sin\theta$ and $r = 2a\cos\theta$ are circles of diameter $2a$ (so radius $R = a$!) with $\theta \in [0, \pi/2]$.
(I), (II), (III) Cartesian Circles x² + y² = R² about x-axis
$V = 2\int_{0}^{R} \pi(R^2 - x^2)\,dx = \frac{4}{3}\pi R^3$,   $S = 2\int_{0}^{R} 2\pi y\sqrt{1 + x^2/y^2}\,dx = 4\pi R^2$.
• (I) $x^2 + y^2 = a^2$ ($R=a$): $V = \mathbf{\frac{4}{3}\pi a^3}, \; S = \mathbf{4\pi a^2}$.
• (II) $x^2 + y^2 = 4$ ($R=2$): $V = \mathbf{\frac{32}{3}\pi}, \; S = \mathbf{16\pi}$.
• (III) $x^2 + y^2 = 9$ ($R=3$): $V = \mathbf{36\pi}, \; S = \mathbf{36\pi}$.
(IV) Polar Circle r = 2a sin θ revolved about θ = π/2 (y-axis)
Limits $\theta: 0 \to \frac{\pi}{2}$. Here $\frac{ds}{d\theta} = \sqrt{4a^2\sin^2\theta + 4a^2\cos^2\theta} = 2a$.
• Surface Area: $S = \int_{0}^{\pi/2} 2\pi (r\cos\theta) \frac{ds}{d\theta}\,d\theta = \int_{0}^{\pi/2} 2\pi (2a\sin\theta\cos\theta)(2a)\,d\theta = 8\pi a^2 \left[\frac{\sin^2\theta}{2}\right]_{0}^{\pi/2} = \mathbf{4\pi a^2}$.
• Volume: $V = \int_{0}^{\pi/2} \frac{2}{3}\pi r^3 \cos\theta\,d\theta = \frac{16}{3}\pi a^3 \int_{0}^{\pi/2} \sin^3\theta\cos\theta\,d\theta = \mathbf{\frac{4}{3}\pi a^3}$.
(V) Polar Circle r = 2a cos θ revolved about θ = 0 (x-axis)
Limits $\theta: 0 \to \frac{\pi}{2}$, $\frac{ds}{d\theta} = 2a$.
• Surface Area: $S = \int_{0}^{\pi/2} 2\pi (r\sin\theta)(2a)\,d\theta = 8\pi a^2 \int_{0}^{\pi/2} \cos\theta\sin\theta\,d\theta = \mathbf{4\pi a^2}$.
• Volume: $V = \int_{0}^{\pi/2} \frac{2}{3}\pi (8a^3\cos^3\theta)\sin\theta\,d\theta = \frac{16}{3}\pi a^3 \left[-\frac{\cos^4\theta}{4}\right]_{0}^{\pi/2} = \mathbf{\frac{4}{3}\pi a^3}$.
