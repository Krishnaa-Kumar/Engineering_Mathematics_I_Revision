Unit 1

Sequences & Infinite Series

View Full Unit
1. Standard Series Convergence Tests 
Ratio Test: lim (u_n / u_{n+1}) = l (l > 1 Conv, l < 1 Div, l = 1 Fails)
Raabe's Test: lim n * [(u_n / u_{n+1}) - 1] = l (l > 1 Conv, l < 1 Div)
p-Series Test: sum (1 / n^p) converges for p > 1, diverges for p <= 1
2. Alternating Series & Leibnitz Test 
Leibnitz Test: sum (-1)^(n-1) u_n converges if:
  (i) u_{n+1} <= u_n for all n (Monotonically decreasing)
  (ii) lim_{n -> inf} u_n = 0
3. Sequence Limits & Classifications 
lim_{n -> inf} (2^n / (n+1)) = inf (Divergent by L'Hopital)
lim_{n -> inf} ((n+1)/n) = 1 (Convergent)
{(-1)^n} oscillates finitely between -1 and +1
4. Taylor & Maclaurin Series Expansions 
f(x) = f(0) + x*f'(0) + (x^2 / 2!)*f''(0) + (x^3 / 3!)*f'''(0) + ...
sin x = x - x^3/6 + x^5/120 - ...
cos x = 1 - x^2/2 + x^4/24 - ...
e^x   = 1 + x + x^2/2 + x^3/6 + ...
Unit 2

Applications of Definite Integrals

View Full Unit
1. Length of Plane Curves (Arc Length Formulas) 
Cartesian:  ds = sqrt(1 + (dy/dx)^2) dx
Parametric: ds = sqrt((dx/dt)^2 + (dy/dt)^2) dt
Polar:      ds = sqrt(r^2 + (dr/dtheta)^2) dtheta
2. Surface Area of Solids of Revolution 
S_x = 2 * pi * int y * sqrt(1 + (dy/dx)^2) dx
S_polar = 2 * pi * int r * sin(theta) * sqrt(r^2 + (dr/dtheta)^2) dtheta
Cycloid Surface about x-axis: S = 64/3 * pi * a^2
3. Volume of Solids of Revolution 
V_x = pi * int_a^b y^2 dx
V_polar = (2/3) * pi * int r^3 * sin(theta) dtheta
Cardioid r = a(1+cos theta) Volume about initial line: V = (8/3) * pi * a^3
4. Standard High-Yield Exam Curves 
Cardioid: r = a(1 + cos theta) => Perimeter = 8a, Surface = (32/5)*pi*a^2
Cycloid:  x = a(t - sin t), y = a(1 - cos t) => Arch Length = 8a
Astroid:  x^(2/3) + y^(2/3) = a^(2/3) => Total Perimeter = 6a
Unit 3

Beta & Gamma Functions & Improper Integrals

View Full Unit
1. Gamma Function & Recurrence Relations 
Gamma(n) = int_0^inf e^(-x) * x^(n-1) dx (n > 0)
Gamma(n+1) = n * Gamma(n) = n!
Gamma(1/2) = sqrt(pi)
int_0^inf e^(-kx) * x^(n-1) dx = Gamma(n) / k^n
2. Beta Function & Symmetry Property 
B(m,n) = int_0^1 x^(m-1) * (1-x)^(n-1) dx
B(m,n) = 2 * int_0^(pi/2) sin^(2m-1)(theta) * cos^(2n-1)(theta) dtheta
B(m,n) = B(n,m)
3. Beta-Gamma Core Relation & Duplication Formula 
B(m,n) = [Gamma(m) * Gamma(n)] / Gamma(m+n)
int_0^(pi/2) sin^p(t) * cos^q(t) dt = [Gamma((p+1)/2) * Gamma((q+1)/2)] / [2 * Gamma((p+q+2)/2)]
Gamma(m) * Gamma(m + 1/2) = (sqrt(pi) / 2^(2m-1)) * Gamma(2m)
4. Convergence of Improper Integrals 
int_a^inf (dx / x^p) converges for p > 1, diverges for p <= 1
mu-Test: lim_{x -> inf} x^mu * f(x) = L (converges if mu > 1 and L is finite)
Unit 4

Multivariable Calculus (Partial Differentiation)

View Full Unit
1. Homogeneous Functions & Euler’s Theorem (1st Order) 
x * (du/dx) + y * (du/dy) = n * u
Three variables: x * u_x + y * u_y + z * u_z = n * u
2. Euler’s 2nd-Order Theorem & Both Key Deductions 
x^2 * u_xx + 2xy * u_xy + y^2 * u_yy = n(n-1) * u
Deduction 1: x*u_x + y*u_y = n * [f(u)/f'(u)] = F(u)
Deduction 2: x^2*u_xx + 2xy*u_xy + y^2*u_yy = F(u) * [F'(u) - 1]
3. Maxima & Minima for Functions of Two Variables 
Stationary Points: f_x = 0 and f_y = 0
Discriminant Delta = rt - s^2, where r = f_xx, s = f_xy, t = f_yy
- If Delta > 0 and r > 0 => Local Minimum
- If Delta > 0 and r < 0 => Local Maximum
- If Delta < 0          => Saddle Point (No Extremum)
- If Delta = 0          => Inconclusive
4. Chain Rule & Total Differential 
du = (du/dx)*dx + (du/dy)*dy
du/dt = (du/dx)*(dx/dt) + (du/dy)*(dy/dt)
Unit 5

Multiple Integrals & Vector Transformations

View Full Unit
1. Double & Triple Integrals (Finding Limits) 
iint_R f(x,y) dy dx = int_a^b [ int_{y1(x)}^{y2(x)} f(x,y) dy ] dx
iiint_V f(x,y,z) dz dy dx = int [ int [ int f dz ] dy ] dx
2. Change of Order of Integration 
int_0^a [ int_{x^2/a}^{2a-x} f(x,y) dy ] dx  <===> Split into sub-regions with horizontal strips dx dy
Sketching the region of integration is mandatory for full marks in PTU.
3. Jacobians & Polar Coordinate Transformations 
J = d(x,y)/d(r,theta) = | cos(t)  -r*sin(t) |
                         | sin(t)   r*cos(t) | = r*(cos^2 + sin^2) = r
dx dy = r dr dtheta
x^2 + y^2 = r^2
4. Applications to Area & Volume Calculation 
Area = iint_R dx dy = iint_R r dr dtheta
Volume = iint_R z(x,y) dx dy
Sphere Volume: iiint dx dy dz = (4/3) * pi * a^3
