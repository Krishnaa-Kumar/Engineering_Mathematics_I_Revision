## 🚀 Overview

**CalcVault M-1** is a complete, interactive revision website engineered specifically for first-year engineering students preparing for the **IKG Punjab Technical University (IKG-PTU BTAM101-18)** Engineering Mathematics-I examinations.

It covers **100% of the syllabus question bank across all 5 units** (26 high-yield exam derivations, standard problem solutions, evaluator tips, and pitfalls) with an interactive whiteboard, step-by-step mathematical proofs, and 1-click printable PDF cheat-sheets.

---

## 🌟 Key Website Features

- **100% Free & Unrestricted Access**: No paywalls, no timed access locks, no subscriptions. Everything is immediately accessible to all students.
- **True Multi-Page Website Architecture**:
  - `index.html`: Interactive Revision Whiteboard & Hub with instant search, unit filters, and animated step-by-step derivation viewer.
  - `unit1.html`: Unit 1 — Sequences & Infinite Series (Ratio, Cauchy, Leibnitz, p-Test, Taylor expansions).
  - `unit2.html`: Unit 2 — Applications of Definite Integrals (Arc length, surface area, and volume of solids of revolution for Cycloids, Ellipses, Cardioids, Circles).
  - `unit3.html`: Unit 3 — Beta & Gamma Functions and Improper Integrals (Definitions, 7 reduction integrals, property proofs, convergence tests).
  - `unit4.html`: Unit 4 — Multivariable Calculus (Partial differentiation, Euler's Theorem 1st & 2nd order with deductions, Chain rule, Maxima & Minima of 2 variables).
  - `unit5.html`: Unit 5 — Multiple Integrals & Applications (Double/triple integrals, limit determination, change of order of integration, polar transformations, Jacobians).
  - `cheatsheet.html`: Dedicated High-Yield Formula Bank & Complete 26-Topic Cheat-Sheet for rapid pre-exam revision.
  - `syllabus.html`: Official IKG-PTU BTAM101-18 Exam Blueprint, marks distribution (Sections A, B, C), and Top 5 evaluator pitfalls.
  - `about.html`: Project background and author credits.
- **Crisp KaTeX Math Typesetting**: High-performance mathematical notation rendered client-side.
- **1-Click Print & PDF Export**: Dedicated `@media print` styling to export the full 26-topic exam guide as a crisp, well-formatted PDF without headers or website clutter.
- **Offline Mastery Tracking**: Track your revision progress across all 26 topics with private browser storage.
- **Dark & Light Mode**: Seamless theme switching with persistence for late-night exam prep.

## 💻 How to Run Locally

Because CalcVault M-1 is built with modern static web standards (HTML5, Tailwind CSS, KaTeX, and Vanilla JavaScript), no complex build step or heavy package dependencies are required:

1. Clone the repository:
   ```bash
   git clone https://github.com/Krishnaa-Kumar/Engineering_Mathematics_I_Revision.git
   cd Engineering_Mathematics_I_Revision
   ```
2. Open in your browser:
   - Simply double-click `index.html` to open it directly in Chrome, Firefox, Safari, or Edge.
   - Or start a lightweight local server:
     ```bash
     python3 -m http.server 8080
     ```
     and navigate to `http://localhost:8080`.
